Christmas Lights Game Offical Rules

Game Duration

  • The game cannot start before December 1st.
  • The game ends at midnight at the start of January 6th.
  • The game starts when any player starts the game and lasts until the game ends.

Game Location

  • The game can only be played from within a moving car.
  • A new round starts upon the start of a new journey.
  • The round ends when the engine is turned off at the end of the journey.
  • A journey can have multiple stages if the desired destination had not been reached when the engine is turned off, in which case the previous round continues on resumption of the journey.
  • No dispensation is given for better or worse seating locations in the car.

Scoring Points

  • A point is scored by the first person to lay a claim to a set of Christmas lights by shouting "Christmas lights" upon the first sighting of any set of Christmas lights.
  • Only the first person can earn a point for each set of Christmas lights. If more than one person simultaneously lays a claim, all people who shouted simultaneously earn a point.

Christmas Lights

  • Christmas lights are defined as any electrically lit lights that would be considered a Christmas decoration by any reasonable person.
  • Examples of Christmas lights:
    • Lights on a Christmas tree
    • Fairy lights
    • Illumianted shapes (e.g. redindeers, presents)
    • Menorahs, lanterns, candles - must be electrically powered
  • Christmas lights of any size count.
  • Any Christmas lights visible from the road count, even if internal to a property and viewed through a window.
  • Multiple Christmas lights on the same property count as part of the same "set" and only score one point.
  • Each set of Christmas lights can only be counted once per journey.

Challenging A Claim

  • Any player can challenge another player's claim if they feel it is invalid.
  • Reasons for an invalid claim include:
    • Not Christmas lights - the lights claimed are normal lights and not associated with Christmas.
    • Permanent Christmas lights - the lights classify as Christmas lights but are normally there, and on, ouside of the game duration.
    • Duplicate claim - the lights have already been claimed in the current round.
    • Hint provided - someone else not involved in the game prompts a player to make a claim.
  • A successful challenge results in the claim being voided and the claiming player not receiving a point.
  • A player is disqualified from the current round if they have two successful claims against them.

Winning The Game

  • The winner is the person with the most points at the end of the round.

"Shooting Fish In A Barrel" Pause

  • The game takes a pause when spotting Christmas lights becomes too easy.
  • The pause starts usually within a week of Christmas day.
  • The pause ends when people start to take down their Christmas lights, usually after January 1st.
  • The start and end of the pause can be suggested by any player, but must be agreed by all players.
  • The start and end of the pause do not need to be decided at the same time.
